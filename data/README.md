# GeoWaveAI Dataset Documentation

## Primary exploration dataset: DeepSubDAS

- Dataset name: DeepSubDAS
- Publisher: Zenodo
- Dataset DOI: 10.5281/zenodo.16014744
- Official record: https://zenodo.org/records/16014744
- Data type: Submarine Distributed Acoustic Sensing (DAS)
- Data format: HDF5 (.h5)
- Research purpose: Earthquake phase picking using DAS recordings
- Available annotations: P-wave and S-wave phase information, as described by the dataset record.

## Data management rules

1. Keep original downloaded files unchanged.
2. Store original data inside data/raw/deepsubdas/.
3. Store processed outputs inside data/processed/.
4. Never upload raw or processed research data to GitHub.
5. Record preprocessing operations and parameters.
6. Verify dataset metadata before interpreting waveform values.

## Licensing and citation

The original Zenodo v1 record does not display a clearly specified dataset license.
Verify the applicable usage terms with the authors before redistribution or
use beyond permitted research access.

Cite the original dataset and its associated research publication when using it.
