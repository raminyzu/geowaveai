
# GeoWaveAI

**GeoWaveAI: An Intelligent Framework for Seismic Signal Processing, Microseismic Event Detection, and Geophysical Data Analysis**

## Project Overview

GeoWaveAI is a research-oriented software project focused on geophysical signal processing and intelligent event detection.

The initial research direction is the detection of weak seismic and microseismic events in noisy Distributed Acoustic Sensing (DAS) recordings.

The project will investigate whether machine learning and deep learning can improve event-detection robustness compared with suitable traditional signal-processing methods.

Borehole acoustic logging may be explored as a separate extension after the initial research pipeline is established.

## Research Objectives

- Understand the structure and characteristics of geophysical signal data.
- Explore signal visualization, preprocessing, filtering, and time-frequency analysis.
- Establish traditional event-detection baselines.
- Develop and evaluate machine-learning and deep-learning approaches where appropriate.
- Compare methods using documented experiments and reproducible evaluation.
- Record limitations, errors, and research findings transparently.

## Technology Stack

The project may use Python, NumPy, SciPy, Pandas, ObsPy, h5py, Matplotlib, scikit-learn, PyTorch, Jupyter, and pytest as needed.

Tools and dependencies will be introduced gradually according to the research requirements.

## Project Principles

- Never fabricate datasets, experimental results, or research findings.
- Verify dataset documentation before using a dataset.
- Keep raw research data and generated model artifacts out of Git.
- Use reproducible experiments and documented evaluation procedures.
- Keep seismic DAS analysis distinct from borehole acoustic logging unless their differences are explicitly addressed.
- Track meaningful development changes using Git and GitHub.
